# scroll_scene example

Scroll‑telling landing page in one file, `lib/main.dart`: pinned hero with
staggered words, a phone that assembles from parts, a horizontal gallery driven
by vertical scroll, an unpinned reveal section and a snapping slide section.
Tap the ruler button to toggle debug markers.

The file depends only on `package:flutter/material.dart` and `scroll_scene`, so
you can paste it over `lib/main.dart` of any new app:

```bash
flutter create scroll_scene_demo
cd scroll_scene_demo
flutter pub add scroll_scene
flutter run
```
